Windows 11

Live now

  1. Open three.ws in Edge and install it (the install icon in the address bar).
  2. Open the widgets board (Win + W) and choose Add widgets.
  3. Pick Agent glance. It refreshes itself every 15 minutes.

Signed out is handled: the widget shows a sign-in card rather than an error, and it keeps the last card it saw when the machine is offline.

Any web page

Live now

The <agent-glance> element above is the whole integration: one module script, one tag. It polls only while it is on screen and the tab is visible.

Android

Live now

  1. Install the three.ws app (version 1.1 or later).
  2. Open this page on the phone, signed in, and tap Link this phone.
  3. Long-press the home screen, choose Widgets, and add Agent glance.

The widget refreshes itself about every 30 minutes without opening the app, keeps the last card it saw when the phone is offline, and opens your agent on tap. It carries its own token, which you can revoke below at any time.

macOS and iOS

Live now

  1. Install the three.ws Glance app on the Mac, or the three.ws iPhone app.
  2. Open this page on that device, signed in, and press Link this device.
  3. Add Agent glance from the widget gallery (Mac: click the date, then Edit widgets).

glw_ Paste this into the app if the link did not open it. It is shown once.

One WidgetKit extension serves both platforms, in small, medium and large. It refreshes on the system's timeline, keeps the last card offline, and opens your agent on click. Same token, revocable below.

Linked widgets

Every linked widget holds its own token that can only read your glance card. Revoke one and that widget shows a "link again" card on its next refresh.
